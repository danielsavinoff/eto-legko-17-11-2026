# Замер скорости скачивания

Консольный скрипт на Node.js без внешних зависимостей. Делает **10 последовательных GET-запросов** к указанному адресу, каждый раз дожидается полного скачивания ответа, затем выводит среднее время запроса, общий объём данных и скорость скачивания.

## Требования

Node.js **22 или новее**. Устанавливать зависимости не нужно.

## Запуск

Из папки проекта:

```sh
npm start -- "https://example.com/large-image.jpg"
```

Замените адрес на доступный URL большого файла. URL с параметрами заключайте в кавычки. Альтернативный запуск:

```sh
node src/index.js "https://example.com/large-image.jpg"
node src/index.js --help
```

Пример формата вывода (цифры условные):

```text
Completed requests: 10
Average request time: 250.00 ms
Total downloaded: 10000000 bytes
Total request time: 2.500 s
Download speed: 32.000 Mbps
```

## Как считаются результаты

- Время каждого запроса измеряется через `performance.now()`: от начала запроса до полного чтения тела ответа, включая ожидание сервера и перенаправления.
- Среднее время — сумма времени 10 запросов, делённая на 10; единица — **миллисекунды (ms)**.
- Объём — сумма фактически прочитанных байтов тел всех 10 ответов, без HTTP-заголовков и накладных расходов протоколов. `Content-Length` для подсчёта не используется.
- Скорость — `общий объём в байтах × 8 / суммарное время в секундах / 1 000 000`; единица — **Mbps (мегабиты в секунду)**, где 1 Mbps = 1 000 000 бит/с. Это отношение общих данных к общему времени, а не среднее арифметическое скоростей запросов.

Ответ читается потоково, без хранения всего файла в памяти. Скрипт просит сервер не использовать кэш (`Cache-Control: no-cache`) и сжатие (`Accept-Encoding: identity`). Если сервер всё же сжимает ответ, Node.js автоматически распаковывает его, и счётчик отражает размер распакованного тела, а не сетевого трафика.

HTTP/HTTPS поддерживаются, перенаправления обрабатываются стандартным `fetch`. Соединения могут переиспользоваться между запросами. На каждый запрос, включая чтение тела, установлен тайм-аут **30 секунд**. При сетевой ошибке, тайм-ауте или HTTP-статусе вне 200–299 скрипт останавливается с кодом 1, не выдавая частичный результат за полный замер.

Это скорость скачивания с конкретного сервера в текущих условиях, а не гарантированная пропускная способность интернет-канала. На результат влияют размер файла, задержка, нагрузка сервера и кэширование. Файл скачивается 10 раз: учитывайте расход трафика и ограничения сервера.

## Тесты

```sh
npm test
```

Тесты используют локальный HTTP-сервер и не требуют доступа в интернет. Проверяют последовательность и полноту 10 загрузок, подсчёт объёма и скорости, обработку HTTP-ошибок и тайм-аута, валидацию URL и консольный интерфейс.
